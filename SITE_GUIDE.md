# СНО кафедры экологии РГАУ-МСХА имени К.А. Тимирязева

Статический сайт на русском языке для GitHub Pages. Не требует установки библиотек, сборки или сервера приложений.

Сайт кафедры: https://ecolog.pro/. Почта для предложений тем и мероприятий: alexandrov_na@rgau-msha.ru.

В `assets/` находятся оригинальный логотип кафедры (PNG), значок плана с прозрачным фоном (`plan-checklist.png`) и план работы СНО на 2026/2027 учебный год (PDF). При публикации загружайте эту папку вместе с остальными файлами сайта.

## Посмотреть сайт

Откройте `index.html` в браузере. Все стили, скрипты и графика находятся в проекте; внешние сервисы и шрифты не используются.

## Заполнить данные

В `site-config.js` задайте:

- `institution` — название вуза или факультета;
- `contactUrl` — ссылку на сообщество, форму записи или адрес с префиксом `mailto:`;
- `contactLabel` — текст кнопки связи;
- `leader` — ФИО и должность руководителя СНО;
- `students` — участники студенческого актива (имя и роль);
- `projects` — проекты преподавателей для студентов;
- `news` — новости мероприятий, организованных с участием СНО;
- `opportunities` — внешние конференции, круглые столы, конкурсы и научные школы;
- `events` — реальные анонсы с названием, датой, местом и ссылкой.

Пока публикации не добавлены, соответствующие разделы показывают сообщения о подготовке материалов. Пока список `students` пуст, отображается приглашение в актив. Формы сбора данных нет. Для регистрации можно указать ссылку на внешнюю форму.

### Новости и внешние возможности

Материалы размещаются вручную: автоматического копирования новостей с других сайтов нет. В `news` добавляйте только события с участием СНО. Кратко перескажите новость и укажите исходную публикацию кафедры или университета. Карточки выводятся от новых к старым.

После изменения конференций, стилей или скриптов выполните `node scripts/prepare-site.cjs` и загрузите обновлённый `index.html` вместе с изменёнными файлами. Команда переносит карточки из `site-config.js` в HTML для отображения без JavaScript и обновляет версии CSS/JS для браузерного кеша. Для этой команды нужен Node.js; самому сайту он не требуется.

Пример элемента `news` (замените пример реальными данными):

```js
{
  title: "Заголовок новости",
  date: "2026-11-09",
  summary: "Что состоялось и как участвовало СНО.",
  source: "Сайт кафедры экологии",
  url: "https://example.org/news"
}
```

В `opportunities` добавляйте внешние мероприятия. `date` — дата начала, `endDate` — дата окончания, `deadline` — крайний срок подачи заявки (последние два поля необязательные). Если срок подачи не подтверждён, используйте `deadlineNote` для пояснения. В `location` можно указать место проведения. Карточки сортируются по дате начала. В `summary` укажите аудиторию, формат и условия; в `source` — организатора. Истекшие объявления удаляйте из массива при обновлении подборки.

```js
{
  title: "Название внешнего мероприятия",
  type: "Конференция",
  date: "2027-03-15",
  deadline: "2027-02-01",
  summary: "Для кого мероприятие, где проходит и как участвовать.",
  source: "Организация",
  url: "https://example.org/conference"
}
```

Для публикации карточки необходимы название, корректная дата `YYYY-MM-DD`, источник и ссылка HTTP(S). Примеры в инструкции не отображаются на сайте. Данные студентов добавляйте в `students` как `{ name: "ФИО", role: "Роль в СНО" }`.

### Проекты для студентов

Преподаватели присылают предложения на `alexandrov_na@rgau-msha.ru`. На странице есть кнопка, открывающая почтовую программу с шаблоном письма. Это подача по электронной почте: проект появляется на сайте после согласования и ручного добавления в `projects` файла `site-config.js`.

```js
{
  title: "Название проекта",
  summary: "Описание исследования и задачи студента.",
  supervisor: "ФИО руководителя",
  email: "руководитель@example.org",
  audience: "Курс, навыки и необходимый опыт",
  outcome: "Ожидаемый результат работы",
  duration: "Сроки и формат работы",
  places: "Число участников"
}
```

Обязательны `title`, `summary`, `supervisor`, `email`. Остальные поля можно опустить. После изменения выполните `node scripts/prepare-site.cjs` и загрузите обновлённые `index.html` и `site-config.js` в репозиторий. Карточки проектов находятся прямо в HTML и отображаются без JavaScript. Пока `projects` пуст, показывается приглашение предложить проект.

Тексты об обществе и вводные материалы редактируются в `index.html`, оформление — в `styles.css`. Перед публикацией проверьте, что описание соответствует работе вашего СНО.

Пример анонса в массиве `events` (замените значения на реальные):

```js
{
  title: "Название семинара",
  date: "2026-12-01",
  location: "Место проведения",
  url: "https://example.org/event"
}
```

## Опубликовать на GitHub Pages

1. Создайте репозиторий GitHub и загрузите в его корень `index.html`, `styles.css`, `script.js`, `site-config.js`, `favicon.svg` и `.nojekyll`.
2. В репозитории откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **Deploy from a branch**.
4. Укажите ветку с файлами сайта (обычно `main`) и папку **/(root)**. Нажмите **Save**.
5. Дождитесь успешной публикации. GitHub покажет адрес сайта на странице настроек Pages.

Обычный адрес сайта проекта: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Для адреса без имени проекта создайте репозиторий `ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io`.

Все локальные ссылки относительные: сайт подходит и для корня домена, и для вложенного пути репозитория.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
